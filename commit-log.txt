Author: RG Sureshkumar

Phase 0: read-only TriCaster probe and TC1 simulator

Probe (tools/probe, no dependencies): finds the TC1 on the cable using
ARP, multicast DNS, UPnP, IPv6 neighbors and a last-resort search of
self-assigned addresses; reads /v1/version and dictionary data; listens
to the port-5951 state stream and change notifications while the TD
walks through guided panel steps; checks file sharing; saves a JSON
results file and a plain-language summary answering the brief's
'Verify on the TC1 first' questions. A single guard module limits it to
GET requests on a fixed read-only list and the register/keep-alive
messages; tests fail if command text appears in its code.

Simulator (tools/simulator): a fake TC1 speaking the same web API,
change notifications and port-5951 protocol, with real-time DDR
playback, DSKs, M/Es (M/E 2 green screen), recording, macros, tally,
practice problems (unplugged, ignored commands, slow replies, LivePanel
password) and a page that logs every command it receives.

Tests run the real probe against the simulator and check the simulator
received zero commands. GitHub Actions runs them on Mac and Windows.
